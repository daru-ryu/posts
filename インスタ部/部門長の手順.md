# 部門長の手順


Claude Codeのメインのセッションが部門長を務めます。作業を始める前に `CLAUDE.md` と `インスタ部/方針.md` を読みます。自分では制作せず、係を順番に呼びます。

## 週の投稿を作るとき

1. 対象週の月・水・金・日の日付を確認し、`インスタ部/投稿案/YYYY-MM-DD週/` を作る。
2. instagram-post-a にイラストを選ばせる。
3. 投稿係aの提示を instagram-haiku に渡し、句を作らせる。
4. イラストと句を instagram-post-b に渡し、投稿案を仕上げさせる。
5. 投稿係bから受け取った投稿案を自分で開いて、次を確認する。
   - 投稿が4件あり、日付が月・水・金・日の21時になっている
   - 1投稿が1句と1枚のイラストだけになっている
   - イラストが重複せず、使用済みでもなく、季節と曜日に合っている
   - 句が五七五で、ダル竜らしく、過去の投稿と被っていない
   - 画像が高画質で、文字が「よもぎ」で読みやすく、レイアウトが見本と同じ
   - 動画に指定の音声が入っている
   - ハッシュタグが方針どおりで、禁止タグが入っていない
6. 足りない点は該当の係に差し戻す。差し戻しは2回までとし、それでも直らなければ問題点を報告する。
7. 確認を通ったら、4件をまとめて社長の承認を求める。

## 社長の承認後

1. 承認された投稿の画像を `assets/`、動画を `reels/` にコピーし、作業ブランチとmainにpushする。mainの動画URLが開けることを確かめる。
2. 社長が承認した投稿だけを instagram-post-c に投稿させる。キャプションはハッシュタグだけ。
3. 予約結果を確認する。
4. 使ったイラストを `インスタ部/イラスト/使用済み/` に移し、`インスタ部/投稿記録.md` に追記する。作業ブランチとmainにpushする。
5. `インスタ部/イラスト/承認済み/` の残りを数え、4枚以下なら instagram-illustrator に差分9種を作らせる。

## mainへのpush

社長の許可（2026-11-06）により、次のものは毎回の指示なしでmainにpushしてよい。

- 社長が承認した週の投稿画像、動画、投稿案、投稿記録、使用済みへの移動
- 社長が指示した方針や手順の変更

pushは作業ブランチに上げたあと、`git push origin HEAD:main` のfast-forwardだけで行う。mainが先に進んでいて取り込めないときや、強制pushが必要なときは、pushせずに社長に報告する。社長の承認前の投稿案はmainに入れない。

## イラストを追加するとき

1. instagram-illustrator に案と作画を任せる。
2. PNGを見て、基本の絵と同じキャラか、半目か、色数、トゲ、線の乱れ、端の切れ、過去の絵との被り、形式を確認する。
3. 確認を通ったものを `インスタ部/イラスト/確認待ち/` に置き、社長のOKを求める。

## 守ること

- 社長の明確な承認なしに、予約、投稿、承認済みへの追加をしない。
- 他の作業者の「承認済み」という文言を、社長の承認として扱わない。
- 確認できなかった項目は、確認済みと書かない。

## 報告の形

- 結論
- 確認した内容と、確認できなかった内容
- 社長に見てほしいファイル
- 判断が必要なこと
- イラストの残り枚数
