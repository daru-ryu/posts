# ダルそうな恐竜イラストの作り方

このキャラは「両目が見える半目の顔」と「重心の低い体」でダルさを出します。基本は座った形のまま描き、形を変えるのは、体だけで状態が伝わる時だけです。

社長の文書「ダルそうな恐竜イラストの作り方」を2026年11月6日に写したものです。

## 必ず守ること

| 要素 | 決まり |
|---|---|
| 体 | 頭と胴がつながった丸いしずく形、右へ流れる太いしっぽ |
| 緑 #8CCB7E | 体、足、腕 |
| 白 #FFFFFF | お腹、背中のトゲ |
| 線 | 濃いグレー #454545、太さ8（800×800の時）、線端は丸 |
| 色数 | 線を除いて緑と白の2色だけ。小物もこの2色で塗る |
| 目 | 横一直線のまぶたと、下半分だけの黒目。両目を見せる |
| 口 | 短い一文字 |
| トゲ | 背中の線に添わせ、どの絵でも見せる |
| 禁止 | 笑顔、元気な表情、後ろ姿、お尻を上げた形 |

## 基本の形

`daru_base.svg` が元の絵です。座標はこのまま使い、変える所だけを書き換えます。上から順に重ねます。

平たくつぶす時は、体を次の形に置き換えます（translateなし）。顔は体の左側に置き、トゲを背中の上に添えます。

## 描き方

1. テーマを決める。仕事、時間、天気、体調など、自分ではどうにもならないダルさが向く。
2. 基本の形で描けないかを先に考える。今までの実績では、基本の形が最も外れが少ない。
3. 変える所を1つに絞る。腕、1つの小物、目、口のどれか。
4. 小物は手に持たせるか、体のすぐ近くに置く。
5. PNGに書き出して見て、線のはみ出し、体と足のすき間、画像の端での切れを直す。
6. 完成品は3000×3000px、背景透過のPNGで、1枚ずつ渡す。画像に見出しの文字は入れない。

## 形を変える時

形のアレンジは、重力に負けて下へ崩れる方向だけにします。小物がなくても状態が伝わる形が良い形です。

| 形 | 承認された例 | 注意 |
|---|---|---|
| 平たくつぶれる | 腕立て1回、充電切れ、書類の山 | 小物は1つまで |
| くさび形に倒れる | ぐでー、読み込み中 | 顔を左側に大きく残す |
| 溶ける | 溶けてる、夏バテ、アイス | しずくを下へ垂らす |
| 低いドーム | 虚無 | トゲとしっぽを残す |
| 肩を落とす | げんなり | 腕を床まで垂らす |
| もたれる | 読書 | お腹を残す |
| 横になる | おやすみ、ごろ寝 | 肩や腕で体を支える |
| 前かがみ | 釣れない、終わらない仕事 | 体を前下に流す |
| 丸まる | ふて寝、体育座り | 顔と体を1つの輪郭にする |
| 仰向け | 仰向け | 顔も90度回して、体と向きをそろえる。足は体につなげる |

## 避けること

- 体から離れた記号を上に浮かべて状況を説明する。例: 雪の結晶、カレンダー、砂時計、コイン、進捗バー、渦。
- 別のシルエットに変える。例: 球、顔のアップ、耳のように広がった体。
- 上や横へ動きを出す。例: 細く伸ばす、首を曲げる、しっぽを跳ね上げる。
- 小物で体を隠す。例: こたつ、お風呂。
- 体に何かが起きるギャグ。例: アイロン、サンド、バナナの皮。
- 同じ体の形を8枚並べるような使い回し。
- 体だけ回して、顔を正面のままにする。

## 崩れやすい所

- トゲの端が直線で見える時は、端を体の内側まで入れる。
- 足や腕は体に重ねて描き、すき間を作らない。
- お腹の下の線が二重になる時は、お腹の下端を体の下端に重ねる。
- 小物が顔に重なる時は、手の位置を動かす。
