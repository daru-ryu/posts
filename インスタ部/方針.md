# インスタ部門の方針

## 運営内容

- アカウント: @daru_ryu
- テーマ: 「ダルい恐竜キャラクターのダルい社会生活575」。常にダルそうな恐竜が、ダルいなーと思いながらも頑張る様子を見せる。
- 1投稿の内容: 五七五1句と1枚のイラストだけ。
- 投稿日時: 月・水・金・日の21時（日本時間）。
- 予約ツール: Metricool（無料プラン、月20件まで）。
- 確認: 内容は週1回まとめて社長が確認する。
- 作成日: 次の週の投稿は毎週土曜に作る。

## 週の流れ

1. 投稿係aが、4投稿分のイラストを季節と曜日に合わせて選ぶ。
2. 575係が、投稿係aの提示した季節、投稿曜日、イラストに合う句を作る。
3. 投稿係bが投稿案を仕上げ、部門長に確認してもらう。
4. 部門長が社長の承認を得る。
5. 投稿係cが、音声を付けて投稿を予約する。

## イラスト

- 使えるのは `インスタ部/イラスト/承認済み/` にあるものだけ。
- 一度使ったイラストは再使用しない。
- 季節が合わないイラストは、時期が来るまで使わない（アイス、夏バテ、残暑、梅雨、花粉など）。
- 社長が週の投稿を承認したら、使ったイラストを `インスタ部/イラスト/使用済み/` に移し、`インスタ部/投稿記録.md` に追記する。
- 移したあとに残りが4枚以下なら、イラスト係が差分9種を追加する。

## 音声

- 使う音声は `インスタ部/素材/音声/dalui_kyoryu_575.wav`（15秒）。
- Metricool経由の写真投稿には、この音声を付けられない。投稿画像に音声を付けた15秒の動画を作り、リールとして投稿する。

## 投稿画像

`インスタ部/投稿案/2026-11-09週/` の画像を見本にする。

- `インスタ部/道具/投稿画像を作る.py` で作る。原本は3000×3000pxのPNGを使い、低解像度の画像から作らない。
- サイズは2160×2700px（4:5）。背景は薄いグレー #F1F1EF。
- 文字は手書き風書体「よもぎ」で、濃いグレーの縦書き。右上から3行に並べる。
- ダル竜は句と重ならないよう、主に左下に置く。右下に小さく「ダル竜」と入れる。
- 動画は `インスタ部/道具/投稿動画を作る.py` で作る。

## 投稿の記録

- 投稿内容の正本は `インスタ部/投稿記録.md`。
- 2026年11月22日までの投稿は決まっている。次に作るのは2026年11月23日の週から。

## キャプションとハッシュタグ

- キャプションはハッシュタグだけにする。句はキャプションに書かず、画像と動画の中に入れる。
- 毎回同じものを使う。
- 「オリジナルキャラクター」「川柳」は付けない。
- 使うタグ: `#ダル竜 #五七五 #恐竜`

## イラストの作り方

- 描き方の正本: `インスタ部/イラスト/参考/イラストの作り方.md`
- 基本の絵: `インスタ部/イラスト/参考/daru_base.svg`
- 迷ったら正本に戻り、判断の記録では新しい判断を優先する。
- `daru_base.svg` をコピーし、変える所だけを書き換える。
- 完成品はSVGとPNGを同じ名前で1組作る。SVGは `viewBox="0 0 800 800"`、PNGは3000×3000px、背景透過で、見出しの文字は入れない。
- ファイル名は `daru_内容.svg` と `daru_内容.png`。内容はローマ字で、過去のものと重ねない。
- 確認を通ったものを `インスタ部/イラスト/確認待ち/` に置き、社長がOKしたものだけ `インスタ部/イラスト/承認済み/` に入れる。
- 社長の判断は「判断の記録」に追記する。判断が「良い」のものは承認済みではない。
- 「ダメと明言」の絵と同じ型は作らない。既存の絵は変更しない。
- 承認済みの絵は、作り方の決まりと違う所があってもそのままでよい（例: ちょっとムッのへの字の口、点目、はてな、こたつ）。ただし、新しい絵の基準にはしない。

- gitのcommitは user.name=daru-ryu、user.email=daru-ryu@users.noreply.github.com で行い、本名を出さない。
